
### Feature Pruning -- Diet Composition (Dc) Group

The diet composition feature group initially comprised 47 features
(35 raw nutrient variables and 12 derived ratios).
To reduce redundancy while retaining biological signal, a two-stage pruning
procedure was applied.

First, variance inflation factors (VIF) were computed within pre-defined
biological clusters (carbohydrate fractions, energy proxies, macronutrients,
dietary fibre, fat subtypes, micronutrients, food groups, and derived ratios).
Features with VIF >= 50 were identified as strong collinearity candidates
(6 features flagged).

Second, SHAP values were computed from an XGBoost model trained on Dc features
alone, and features were ranked by mean absolute SHAP value within each cluster.
Features with VIF >= 50 that fell in the bottom 50% of their cluster by
SHAP importance were removed; features with VIF >= 100 were removed unless
they were the highest-ranked feature in their cluster.

This procedure reduced the Dc feature set from 47 to 44
features (3 removed: KJ, fat_cho_ratio, fibre_cho_ratio). Cross-validation
confirmed that pruning did not meaningfully reduce predictive performance
(dR2 = 0.0056, dMAE = 0.15 mmol*min). The pruned feature set
was used for all subsequent analyses.
